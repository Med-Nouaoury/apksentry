# ApkSentry

**فحص تطبيقات أندرويد (APK و APKS و XAPK) على هاتفك، قبل تثبيتها.**

[English](README.md) · [التحميل](../../releases) · [الدقة المقاسة](#الدقة-المقاسة) · [حدود الفحص](#حدود-الفحص)

</div>

---

يفحص ApkSentry ملف التطبيق **قبل** تثبيته، ويشرح بلغة بسيطة ما يستطيع التطبيق فعله، وهل فيه علامات برنامج خبيث أو تعديل. صُمّم لمن يثبّت تطبيقات من خارج Google Play.

- **الفحص كله على الهاتف.** لا يُرفع أي ملف. البحث في قواعد البيانات اختياري، ويرسل البصمة (SHA-256) فقط، بمفاتيحك أنت.
- **بدون مكتبات خارجية للتحليل.** قراءة ZIP و AXML و Dalvik و ELF والتوقيعات كلها مكتوبة داخل المشروع.
- **أرقام مقاسة، لا وعود.** نسبة الكشف ونسبة الإنذار الكاذب تأتيان من قياس على فيروسات حقيقية يمكن لأي أحد إعادته.

## كيف يعمل؟

كل فحص يعطي درجتين مستقلتين وخلاصة بكلام بسيط:

| الدرجة | السؤال الذي تجيب عنه |
|---|---|
| **درجة الخطر** (0–100) | هل يتصرّف الكود مثل برنامج خبيث؟ |
| **درجة التعديل** (0–100) | هل عدّل التطبيقَ أو أعاد توقيعه طرفٌ غير مطوّره؟ |

| درجة الخطر | الحكم |
|---|---|
| 0–9 | منخفض: لم نجد علامات خطر (وهذا ليس ضماناً) |
| 10–34 | منخفض إلى متوسط: ملاحظات بسيطة |
| 35–59 | متوسط: راجع التفاصيل قبل التثبيت |
| 60–100 | مرتفع: لا تثبّته |

### الكود والسلوك

| الطبقة | ما تفعله |
|---|---|
| **محاكي Dalvik (فك التغليف)** | الفيروسات المغلّفة تحمل كودها الحقيقي مشفّراً وتفكّه وقت التشغيل. يشغّل ApkSentry كود البداية داخل محاكي مكتوب خصيصاً لذلك، ويلتقط الكود الحقيقي لحظة تحميله ثم يحلّله، ولو كان مغلّفاً بعدة طبقات. المحاكي معزول: لا ملفات حقيقية، ولا إنترنت، ولا أوامر، مع حدود للخطوات والذاكرة والوقت. |
| **قواعد السلوك** | أكثر من 20 قاعدة لعائلات أندرويد الخبيثة: أحصنة طروادة البنكية، والشاشات المزيّفة، وسرقة الرسائل ورموز التحقق، وتسجيل ما تكتبه، وتبديل ما تنسخه، وبرامج الفدية، والـ droppers، والأبواب الخلفية، وخدمات VPN الخبيثة. تميّز القواعد بين *القدرة* و*السلوك*، فالصلاحية وحدها لا تُعدّ دليلاً. |
| **تتبّع البيانات** | يتتبّع بياناتك الشخصية (معرّف الجهاز، والموقع، وجهات الاتصال، والرسائل، والحافظة، والحسابات، والإشعارات، ونصوص الشاشة) من مصدرها حتى الإنترنت أو الرسائل. |
| **تحليل الكود** | فك كل تعليمات DEX مع مخطط التدفّق، ومن يستدعي ماذا، والنصوص المشفّرة ودوال فكّها. |
| **المكتبات native** | الوظائف المصدّرة والمستوردة، واستدعاءات النظام المباشرة، والأجزاء المشفّرة، ونصوص مكافحة التحليل. |

### الهوية والسلامة

| الطبقة | ما تفعله |
|---|---|
| **التحقق من التوقيع** | تحقق تشفيري حقيقي من توقيع v2/v3: أي بايت تغيّر بعد التوقيع يُكتشف. |
| **التوقيع الرسمي** | مقارنة مع النسخة المثبّتة من Google Play، ومع قائمتك الموثوقة، وكشف مفتاح الاختبار العلني لـ AOSP. |
| **انتحال الهوية** | يقرأ اسم التطبيق الظاهر بكل اللغات ويقارنه بنحو 40 تطبيقاً مشهوراً: الأخطاء الإملائية المقصودة، والحروف السيريلية المشابهة، والأرقام مكان الحروف، والحزم المقلّدة بحرف واحد. |
| **السمعة (F-Droid)** | قائمة بتوقيعات كل تطبيقات F-Droid، تُحدَّث أسبوعياً. التطابق التام يعني نسخة مبنية من الكود المصدري ومراجَعة. |
| **أدوات التعديل** | MT Manager و NP Manager و Lucky Patcher و Xposed، وأدوات الحماية التجارية، وأدوات التغليف المجهولة. |
| **حيل الإخفاء** | طرق ضغط مزيّفة، وعلامات تشفير مزيّفة، وإغراق الصلاحيات، وحروف خفية في الأسماء. |

### قواعد بيانات الفيروسات (اختياري)

| الطبقة | ما تفعله |
|---|---|
| **البحث بالبصمة** | في MalwareBazaar و VirusTotal، للحزمة ولكل ملف بداخلها، بمفاتيحك المجانية. |
| **التشابه (TLSH)** | بصمة تقريبية تكشف النسخ المعدّلة قليلاً من فيروسات معروفة، بدون إنترنت. مطابقة بنسبة 100% للمكتبة المرجعية `py-tlsh`. |

### الثغرات في التطبيق نفسه

تُعرض منفصلة عن درجة الخطر: قبول أي شهادة SSL، وتجاهل أخطاء SSL في WebView، وتشفير ضعيف، ومفاتيح مكتوبة في الكود، ومكوّنات مكشوفة، واتصالات غير مشفّرة، وأسرار مسرّبة (مفاتيح AWS و Stripe، وتوكنات GitHub و Slack، وبوتات تيليغرام وروابط Discord المستعملة لتسريب البيانات).

## الدقة المقاسة

يُقاس المحرك بالسكربت [`bench/benchmark.py`](bench/benchmark.py) على فيروسات أندرويد حقيقية من [MalwareBazaar](https://bazaar.abuse.ch/) وتطبيقات سليمة من [F-Droid](https://f-droid.org/)، داخل خوادم GitHub Actions المؤقتة. تُحذف العيّنات بعد الفحص.

**آخر قياس: الإصدار 3.7.2، نوفمبر 2026.** شمل 246 فيروساً من 25 عائلة، و382 تطبيقاً سليماً.

| حد الخطر | الفيروسات المكتشفة | التطبيقات السليمة المُنذَر بها خطأً |
|---|---:|---:|
| ≥ 10 | 95.5% | 23.6% |
| **≥ 35** | **91.9%** | **8.1%** |
| ≥ 60 | 84.6% | 3.7% |

- القياس يشغّل **المحرك وحده**، بدون قواعد البيانات ولا TLSH ولا السمعة، لأن العيّنات مأخوذة من المصادر نفسها.
- أغلب الإنذارات الكاذبة تطبيقات سليمة **مزدوجة الاستعمال** (تحكّم عن بعد، وتحديد موقع الجهاز، وقفل التطبيقات). في التطبيق، طبقة السمعة تتعرّف على نسخها الرسمية.
- التطبيقات السليمة تُؤخذ من آخر إصدارات F-Droid، فتتغيّر قليلاً بين قياس وآخر، وهذا وحده يحرّك نسبة الإنذار الكاذب بنقطة تقريباً.
- عيّنات MalwareBazaar أغلبها عائلات بنكية معروفة. نسبة الكشف على الفيروسات الجديدة أو الموجّهة ستكون أقل.

## جدار الحماية لكل تطبيق

الفحص الثابت لا يرى ما يفعله الكود المشفّر أو native وهو يعمل، لذلك يتضمّن ApkSentry جداراً ناريّاً محلياً عبر VPN، بدون أي خادم خارجي.

- **اقطع الإنترنت عن أي تطبيق** مباشرة من نتيجة فحصه. القطع **دائم**: يبقى بعد إغلاق ApkSentry، ويعود تلقائياً بعد إعادة تشغيل الهاتف أو تحديث التطبيق.
- **راقب تطبيقاً مباشرة:** كل موقع يطلبه يظهر مصنّفاً (معروف، إعلانات وتتبّع، غير مألوف، مشبوه)، ويمكن منعه بضغطة.
- تُحسب محاولات الاتصال الممنوعة لكل تطبيق.

الأندرويد يسمح بـ VPN واحد في نفس الوقت. لأقوى حماية بعد إعادة التشغيل، فعّل **VPN الدائم** (Always-on VPN) لـ ApkSentry من إعدادات الهاتف.

## التثبيت

حمّل `ApkSentry.apk` من صفحة [Releases](../../releases). كل إصدار يُبنى تلقائياً من هذا الكود عبر GitHub Actions، وبصماته في `SHA256SUMS.txt`.

يتطلّب أندرويد 8.0 أو أحدث.

## على الحاسوب

المحرك نفسه متوفّر كأداة سطر أوامر (`apksentry-cli.jar`، يتطلّب Java 17):

```bash
java -jar apksentry-cli.jar app.apks --out report.txt
java -jar apksentry-cli.jar app.apk --mb <مفتاح_MalwareBazaar> --vt <مفتاح_VirusTotal>
```

## حدود الفحص

- **لا يوجد فحص يضمن الأمان.** الدرجة المنخفضة تعني أننا لم نجد علامات خطر، لا أن التطبيق آمن.
- **الكود native لا يُشغَّل.** إذا كان الكود الحقيقي يُفك داخل مكتبة native، فلا يمكن رؤيته. يقول التطبيق ذلك صراحة، وإذا كان الكود كله تقريباً مخفياً بهذه الطريقة، لا يُعطى حكماً منخفض الخطر.
- **تتبّع البيانات تقريبي**، وقد يفوته مسار يمر عبر reflection أو كود native.
- **قد تنطبق قواعد السلوك على أدوات سليمة** تحتاج فعلاً صلاحيات حساسة. كل ملاحظة معروضة مع سببها لتحكم بنفسك.
- **توقيع v1 القديم يُقرأ ولا يُتحقق منه تشفيرياً**؛ الأندرويد يتحقق منه عند التثبيت.
